## **1. 기능 요구사항**

**ID 체계** — `대분류-소분류-번호`

| 대분류 접두어 | 원어 | 의미 |
| --- | --- | --- |
| FR | Functional Requirement | 기능 요구사항 |
| NFR | Non-Functional Requirement | 비기능 요구사항 |

| 소분류 접두어 | 원어 | 의미 |
| --- | --- | --- |
| USR | User | 계정·연동·온보딩 |
| TXN | Transaction | 거래 수집·분류 |
| BGT | Budget | 예산 봉투 |
| PAY | Payment | 정기 지출·결제 준비 |
| GAM | Gamification | 방·캐릭터·코인 |
| AI | AI | 코칭 에이전트 |
| NTF | Notification | 알림 |

예시: `FR-USR-01`, `NFR-AI-01`
