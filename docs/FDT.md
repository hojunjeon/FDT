# KeyFin 개인 금융 디지털 트윈 (PFDT) 기능 명세서 (v1.0)

본 문서는 실제 자산 이체·결제 등의 금융 실행 동작을 배제하고, 금융 데이터 분석 기반의 결정론적 디지털 트윈(FDT) 시뮬레이션 및 자연어 코칭·시각화에 집중한 기능 명세서입니다.

---

## 1. 시스템 설계 원칙

* **환각 없는 금융 코어 (Deterministic Backend)**: 잔액 계산, 상태 전이, 미래 궤적 시뮬레이션, 이상 탐지 등 모든 숫자 연산은 100% 백엔드 규칙 및 수학 알고리즘이 전담합니다.
* **자연어 및 비정형 처리 어댑터 (AI Layer)**: AI(SLM/LLM)는 비정형 가맹점명 분류, 사용자 자연어 질의의 파라미터 추출, 백엔드 산출 수치를 기반으로 한 페르소나 코칭 텍스트 생성에만 한정 적용합니다.
* **불변 원장과 가상 샌드박스 분리**: 실제 원장 데이터(State(t))는 불변으로 보호하며, What-if 시뮬레이션은 독립된 인메모리 포크(Fork) 공간에서만 연산 후 폐기합니다.

---

## 2. FDT 데이터 모델 규격

| 구성 요소 | 식별자 | 포함 데이터 | 역할 |
| :--- | :--- | :--- | :--- |
| **현재 상태 스냅샷** | State(t) | • 가용 유동성: 자유 입출금 및 비상금 잔액<br>• 약정 지출 큐: 카드 청구 예정액, 월세 등 고정비<br>• 예산 봉투: 7대 카테고리 잔여 한도<br>• 행동 지표: 7일 지출 가속도, 미확정 건수 | 시뮬레이션의 기준점이 되는 실시간 동기화 객체 |
| **개인화 행동 모델** | Behavior | • 요일/주기별 소비 확률 밀도 함수<br>• 잔여 예산 대비 충동 지출 탄력도 | 시뮬레이션 루프 진행 시 일자별 가상 지출(Action) 생성 |
| **회계 전이 함수** | Transition | • 신용카드 승인 시 봉투 차감 및 청구 큐 누적 규칙<br>• 결제일 도래 시 유동성 차감 규칙 | 금융의 물리 법칙에 따라 다음 날 상태(State(t+1))를 산출하는 순수 함수 |

## 4. 데이터 흐름 파이프라인

1. **[사용자 입력 및 금융 원천 데이터 수집]**
   * 사용자 자연어 채팅 질의 및 금융망 결제/잔액 데이터 인입

2. **[1단계: AI 입력 어댑터 레이어]**
   * 비정형 가맹점명 정제 (KoELECTRA)
   * 자연어 질의에서 의도 및 파라미터(금액, 카테고리) 정형 JSON 추출 (LLM Tool Calling)

3. **[2단계: FDT 코어 엔진 (결정론적 백엔드)]**
   * 정형 데이터를 State(t) 스냅샷에 반영 및 회계 전이 함수 실행
   * What-if 메모리 샌드박스 포크 및 30일 잔액 궤적 비교
   * 동적 Safe-to-Spend 계산 및 50% 룰 우려 결제 감지
   * 결과 데이터를 정규화된 수치 JSON으로 확정

4. **[3단계: 출력 인터페이스 (UI 시각화 및 자연어 코칭)]**
   * UI Chart: 30일 잔액 궤적 그래프, 리스크 게이지 렌더링
   * AI Coaching: 계산된 수치 변형 없이 페르소나 캐릭터 말풍선 대화 생성
   * Visual: 방 날씨 및 캐릭터 애니메이션 상태 변경 투영
